# MAX — QR-пилот тестового диалога

Отдельное локальное дополнение HA для arm64. Для проверки используйте только тестовый аккаунт, отдельного тестового бота и закрытую тестовую группу. Этот пилот читает только входящие текстовые метки формата MAX HA TEST 8432 из одного явно заданного диалога. Позиция строки используется только после проверки сохранения полного префикса видимых тестовых меток. При пропуске, перестановке или подгрузке, меняющей этот префикс, пересылка останавливается. Это не устойчивый ключ для произвольных рабочих чатов.

1. Распакуйте папку в каталог локальных приложений HA и установите «MAX — QR-пилот тестового диалога».
2. Укажите локально произвольную метку тестового аккаунта, точное имя отправителя в списке диалогов, имя отдельного тестового бота, его токен и числовой ID закрытой тестовой группы. Включите test_confirmed. Для первичной проверки в диалоге уже должна быть одна входящая метка.
3. Запустите пилот и откройте панель. Войдите тестовым телефоном по QR. Дождитесь статуса «Пилот слушает тестовый диалог», затем отправьте новую метку, например MAX HA TEST 8433. Проверьте карточку и кнопку в закрытой тестовой группе.
4. Перезапустите пилот, проверьте сохранение входа и отсутствие повторной карточки. Отправьте такую же метку снова и проверьте появление новой карточки.

Профиль Chromium и SQLite хранятся в /data. Доступ к резервным копиям с профилем ограничьте как доступ к аккаунту. Chromium запускается с sandbox. Если контейнер HA не предоставляет требуемую поддержку sandbox, пилот остановится. Образ и браузер внутри HA ещё не проверены. Пилот не поддерживает фото, телефон и произвольные тексты. Имена берутся из заданного тестового диалога. Публикация в закрытую группу осуществляется только тестовым ботом после проверки его имени, членства и отсутствия Webhook.
