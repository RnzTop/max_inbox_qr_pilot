# MAX — PyMax только тест (без отправки)

**Экспериментальный прототип**, не для рабочего аккаунта. Исходники только в черновой ветке; образ собирается локально из проверенных исходников. Папка пригодна для локальной сборки Home Assistant Supervised на `aarch64`, но реальная совместимость PyMax с текущим MAX ещё не подтверждена.

- Вход через `PyMax WebClient` и QR; Chromium не нужен.
- Если PyMax не показывает имя личного диалога (`Chat.title=None`), в панели появляется одноразовая метка `MAX HA PAIR ...`. Её нужно отправить из второго тестового аккаунта в нужный чат. ID чата выбирается только после точного совпадения метки; при перезапуске может потребоваться повторная привязка. Не публикуйте метку.
- Подключение только отдельного тестового номера. В параметрах обязательны `test_confirmed`, метка аккаунта и точное название тестового диалога.
- Наблюдение исключительно за **новыми входящими метками** `MAX HA TEST 1234` выбранного диалога. Ни сообщения, ни их ID, ни названия чатов в логах и базе не сохраняются.
- Для каждого нового сообщения сохраняется только HMAC-отпечаток пары `chat_id + message.id` (секрет в `/data/pymax_test/key.bin`). При перезапуске повторный ID не увеличивает счётчик уникальных.
- QR показывается только в локальной HA ingress-панели, а не в логах; не пересылайте снимки QR.
- **Никакого Bot API, polling, webhook, пересылки, ответов, отмечания прочитанным и просмотра истории.**
- Невозможно гарантировать, что веб-клиент не отправляет внутренние служебные пакеты MAX; «только чтение» означает отсутствие **наших** операций отправки сообщений.
- Пока тестируете браузерный QR-пилот, **не запускайте одновременно PyMax для того же номера** — возможны конфликты сессий.

Пошаговая установка и безопасная проверка описаны в [DOCS.md](DOCS.md). Остановите QR-пилот и установите эту папку как отдельное локальное дополнение (изображение собирается локально один раз). Для первого старта подтвердите тестовый режим и точное имя тестового диалога. Откройте ingress, отсканируйте QR, затем отправьте `MAX HA TEST 8351` из другого тестового аккаунта в указанный диалог. На панели должен увеличиться счётчик уникальных сообщений.

**Безопасность:** Сессия `/data/pymax_session.db` предоставляет полный доступ к тестовому аккаунту. Ограничьте доступ к папке и её резервным копиям. PyMax — неофициальный клиент MAX, его использование может быть ограничено условиями сервиса. Перед любым рабочим применением нужен отдельный тест на стабильность, восстановление соединения и пропущенных сообщений.
